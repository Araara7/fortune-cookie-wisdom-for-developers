One original fortune-cookie line for a software developer, for the [Fortune Cookie Wisdom for Developers](https://make.fun/bounty/u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44) bounty on make.fun.

## The fortune

> Legacy code is a letter from a stranger who knew exactly what they were doing, once.

84 characters, one line. It reads like a real fortune cookie — one short balanced sentence that lands in a single breath — it is true about a developer's day (every senior engineer has inherited legacy code), and it turns that truth in a way you have not heard before: "once" carries a double meaning, at one time and only once, rewarding a second read.

## How it works

`main.py` writes the line to `/output/entry.txt`, deterministically (repeated runs produce byte-identical output, verified by a read-back check).

```sh
python3 main.py
```
